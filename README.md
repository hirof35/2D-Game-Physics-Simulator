ゲーム開発における「弾の移動（等速直線運動）」と「プレイヤーのジャンプ（重力加速度）」の2つの基本ロジックを、テキストベースのシミュレーションで視覚的に確認できます。
📌 機能概要本プログラムは、メインメニューから2つの異なる物理シミュレーションを選択して実行できます。
弾発射シミュレーション (Player & Ball クラス)プレイヤーの現在地から指定した速度で弾を右方向へ発射します。
弾が画面外（X座標が800を超えるなど）に出るまで、一定時間ごとに座標を更新し続けます。
ジャンプシミュレーション (Jump_Player クラス)重力加速度を考慮した本格的な放物線ジャンプをシミュレートします。
ジャンプ初速から徐々に減速し、最高点に達したあと下降して地面（Y=10）に着地するまでの挙動を再現しています。
🛠️ 技術スタック言語: Python 3.x標準ライブラリ: time（シミュレーションのウェイト処理用）
🚀 使い方1. 実行方法スクリプトが保存されているディレクトリで以下のコマンドを実行してください。
Bashpython main.py
(※ファイル名が main.py の場合)2. 操作方法起動するとコンソールにメニューが表示されます。
数字を入力して Enter を押してください。
メインメニュー1: 弾発射シミュレーションへ2: ジャンプシミュレーションへ0: プログラムを終了弾発射シミュレーション内1 を入力後、弾の移動速度（数値）を入力するとシミュレーションが始まります。0: メインメニューに戻るジャンプシミュレーション内1: ジャンプを実行（空中でもう一度 1 を押しても多段ジャンプはできず、警告が出ます）0: メインメニューに戻る📁 クラス構成プログラムは以下の主要クラスで設計されています。
クラス名役割主要プロパティ / メソッドBall弾のオブジェクト。位置、速度、有効フラグを管理。x, y, vx, vy, isActivePlayer弾を発射するプレイヤー。
弾の生成と座標更新を担当。shoot_ball(), update_ball()Jump_Playerジャンプを行うプレイヤー。重力計算と着地判定を担当。jump(), update_jump_state()
📝 設計のポイント（注意点）画面範囲の仮想設定: 弾発射シミュレーションでは、画面サイズを X: 0〜800 / Y: 0〜600 と仮定しており、この範囲を逸脱すると弾オブジェクトは自動的に非アクティブ (isActive = False) になります。
簡易的な物理演算: ジャンプ時の重力計算は、毎フレームごとに vy -= gravity を行い、座標に加算するオイラー法に近い簡易的な方式を採用しています。
地面の高さは Y = 10 と固定されています。
